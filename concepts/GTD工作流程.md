# GTD工作流程

## 概念 (Concept)

**GTD（Getting Things Done）**：由[[戴维·艾伦]]提出的个人管理系统，通过五个步骤管理任务和项目。主要用于管理[[浮浅工作]]，与[[深度工作]]互补。

## 价值 (Value)

GTD的价值：
- 系统化管理任务
- 减少"遗忘"焦虑
- 清理大脑负担
- 提高执行效率

与深度工作互补：
- GTD管理浮浅工作
- 深度工作专注重要事项
- 结合使用效果最佳

## 用法 (Usage)

### 五个步骤

GTD工作流程五步骤：

1. **收集（Capture）**：
   - 将所有事务收集起来
   - 记录所有想法、任务、承诺
   - 使用收集工具（笔记本、应用）

2. **整理（Clarify）**：
   - 处理收集的内容
   - 判断是否需要行动
   - 确定下一步行动

3. **组织（Organize）**：
   - 将任务放入相应清单
   - 分类：项目、下一步行动、等待、 someday
   - 添加截止日期和提醒

4. **回顾（Reflect）**：
   - 定期回顾所有清单
   - 每周回顾最佳
   - 更新和调整

5. **执行（Engage）**：
   - 根据情境选择任务
   - 时间、精力、优先级
   - 执行选定任务

### 清单系统

GTD使用多个清单：
- **下一步行动清单**：可执行的任务
- **项目清单**：多步骤的目标
- **等待清单**：委托他人的任务
- ** someday清单**：未来可能做的事
- **日程表**：固定时间的任务

## 原理 (Principle)

### 清空大脑

GTD的核心原理：
- 外部系统管理任务
- 大脑不需要记忆
- 减少认知负担
- 专注于执行

### 情境执行

根据情境选择任务：
- 在办公室：处理办公任务
- 在电脑前：处理电脑任务
- 有电话时：处理电话任务
- 有时间时：处理耗时任务

### 两分钟原则

如果一个任务可以在两分钟内完成：
- 立即执行
- 不要记录到清单
- 立即解决

## 心法 (Best Practices)

### 与深度工作结合

GTD与深度工作结合：
1. 用GTD管理浮浅工作
2. 用深度工作处理重要事项
3. 清理浮浅后专注深度
4. 深度工作后用GTD处理积累的任务

### 定期回顾

每周回顾的重要性：
- 清理收集箱
- 更新所有清单
- 评估项目进展
- 规划下周任务

### 不要过度GTD

GTD的局限：
- 容易陷入管理系统本身
- 可能浮浅工作主导
- 需要保护深度工作时间

纽波特建议：
- GTD管理浮浅
- 深度工作优先
- 不要让GTD取代深度
