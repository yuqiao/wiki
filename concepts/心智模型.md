# 心智模型

## 概念 (Concept)

心智模型（Mental Model）是我们对世界的内在表征——脑海中关于"事情应该是怎样的"图像。它帮助我们在混乱环境中聚焦于真正重要的信息。

克莱恩咨询公司研究发现：能在混乱中保持冷静的人（消防员、护士、飞行员），都有强大的心智模型。

## 价值 (Value)

**为什么心智模型重要？**

1. **避免认知隧道**：在突发情况下，大脑倾向于盯着最明显的信息。心智模型提供"应该看哪里"的指引
2. **提高预测能力**：有模型的人能预测接下来发生什么
3. **快速识别异常**：达琳护士脑中有"健康婴儿的图像"，一眼看出异常
4. **减少反应时间**：不需要搜索信息，因为已经知道应该关注什么

**认知隧道的危险**

法航447空难：警报响起时，飞行员只盯着眼前最明显的信息（速度表），而不是整体状况（飞机姿态）。结果做出错误反应，导致228人死亡。

## 用法 (Usage)

**如何构建心智模型？**

1. **预演可能发生的事**：
   - 澳航32号机长德·克雷斯皮尼在起飞前问机组："如果引擎出现故障，你应该先看哪儿？"
   - 测试紧急情况下应该看哪些显示屏

2. **想象"正常状态"**：
   - 达琳护士脑中有健康婴儿的图像
   - 正常状态下，婴儿皮肤什么样、哭声什么样、反应什么样

3. **不断更新模型**：
   - 每次经历后，问"我学到了什么？模型需要调整吗？"

4. **分享模型**：
   - 德·克雷斯皮尼让机组知道他的模型，也听取他们的意见
   - "如果你注意到所有人都在向下看，向上看"

## 原理 (Principle)

**心智模型的工作机制**

大脑是预测机器：
- 系统不断生成关于"接下来会发生什么"的预测
- 预测与现实的差距产生注意力聚焦
- 有心智模型的人，预测更准确，注意力聚焦更有价值

**自动化的陷阱**

自动化时代，大脑习惯被动反应：
- 自动驾驶让飞行员失去主动构建模型的能力
- 当警报响起，大脑没有"应该看哪里"的指引
- 陷入认知隧道：只盯着最明显的信息

**心智模型 vs 反应性思维**

| 心智模型 | 反应性思维 |
|---------|-----------|
| 主动预测接下来发生什么 | 等警报响起才反应 |
| 知道应该看哪里 | 搜索最明显的信息 |
| 快速识别异常 | 被信息淹没 |
| 有准备 | 临时应对 |

## 心法 (Best Practices)

**一句话总结**：心智模型是"预演未来"的习惯——不断问"接下来会发生什么？如果出问题，我首先应该做什么？"

实践要点：
- 不要等危机发生才思考应对方案
- 在脑海中有"正常状态"的图像，才能识别异常
- 模型需要不断更新：每次经历后反思
- 与他人分享模型：不同视角能发现问题

与其他概念协同：
- 与[[心理安全]]：安全环境下，成员可以分享各自的心智模型
- 与[[延展目标]]：延展目标需要新的心智模型
- 与[[概率思维]]：心智模型帮助估计不同结果的概率
