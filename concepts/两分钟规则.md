# 两分钟规则

## 概念

两分钟规则是[[行为转变四定律]]中第三定律"让它简便易行"的具体应用：新习惯的开始应该不超过两分钟。

## 原理

### 为什么两分钟

- **最小阻力**：两分钟以内几乎不需要意志力
- **避免启动恐惧**：极小任务不会触发大脑的防御机制
- **建立启动惯性**：一旦开始，更容易继续

### 阻力最小化

> "习惯的形成是一个行为通过重复逐渐变得更加自动化的过程。最有效的学习形式是付诸实践，而不是纸上谈兵。"

## 用法

### 缩小规模

把大习惯缩小到两分钟版本：

| 大习惯 | 两分钟版本 |
|--------|------------|
| 每晚阅读一小时 | 读一页书 |
| 做瑜伽三十分钟 | 拿出瑜伽垫 |
| 每周跑步三次 | 穿上跑鞋 |
| 每天写日记 | 打开日记本写一句话 |

### 关键洞察

**目标是启动**：两分钟规则的目标是建立习惯的开始，不是完成整个习惯。

**规模化**：习惯形成后，可以逐步扩展：
```
读一页书 → 读三页 → 读十分钟 → 读三十分钟
```

## 与习惯形成的关系

### 习惯基于频率

> "习惯的培养不在于时间长短，而在于重复的次数。"

重复次数比时间总量更重要：
- 30天内做2次 vs 30天内做200次
- 频率决定习惯形成速度

### 自动性曲线

- 开始时：需要极大努力和专注
- 重复后：变得容易但仍需有意为之
- 习惯形成：无需有意为之，自动完成

## 价值

**降低门槛**：任何人都能在两分钟内完成一个极小任务。

**建立惯性**：开始是最难的部分，两分钟规则解决启动问题。

**避免酝酿陷阱**：酝酿不等于行动，两分钟规则强迫执行。
