# 概念 (Concept)

审视自身思考的能力——"思考自己的思考"。人类的终极能力，也是成长的底层驱动力。

元认知让我们能够：
- 观察自己的思维过程
- 判断思考的质量和方向
- 调整思维策略

比喻：元认知是大脑的"飞行模式"，让我们"飞"到高空俯瞰自己的思维，而不是困在地面被本能和情绪牵着走。

# 价值 (Value)

元认知是人与人差异的根本来源。元认知能力强的人：
- 能发现自己的思维盲点
- 能主动调整错误方向
- 能持续优化认知系统

元认知能力弱的人：
- 被本能和情绪主导不自知
- 重复同样的错误
- 成长停滞

# 用法 (Usage)

## 被动元认知

遇挫折时反思：为什么失败？哪里出错？怎么改进？
大多数人只有被动元认知，被问题逼着才反思。

## 主动元认知

平时持续审视：我现在在做什么？为什么要做？方向对吗？效率高吗？
主动元认知是高手的习惯，不等挫折就持续优化。

## 提升方法

1. **每日反思**：复盘当天最触动自己的点
2. **阅读高人智慧**：借助他人的元认知视角
3. **冥想**：训练观察自己念头的能力
4. **记录决策过程**：写下思考过程便于事后审视

# 原理 (Principle)

## 元认知的位置

元认知位于理智脑，但能观察本能脑和情绪脑的运作。
当元认知启动时：
- 本能脑的反应被"看见"
- 情绪脑的冲动被"觉察"
- 理智脑的选择被"评估"

## 元认知的工作流程

1. 觉察：发现当前的思维/情绪/行为状态
2. 分析：判断这个状态是否符合目标
3. 调整：制定优化方案并执行
4. 循环：持续觉察→分析→调整

# 心法 (Best Practices)

## 最佳实践

- 遇事先停一停：给元认知启动时间
- 问自己"为什么"：追溯行为背后的思维
- 假设旁观者视角：如果别人看到我现在这样做，会怎么评价？
- 记录反思：不记录的反思会遗忘

## 反模式

- 情绪上来了立刻行动（元认知来不及启动）
- 从不反思（同样错误反复犯）
- 只在失败后反思（被动元认知效率低）
- 反思不记录（无法积累和迭代）
