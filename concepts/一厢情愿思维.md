# 一厢情愿思维

批判性思维的最大障碍。希望什么是真的就相信它是真的，而非基于确凿证据。包括"相信内心而非真相"（truthiness）和奇迹式思维。

## 概念（Concept）

[[学会提问]]第13章识别的批判性思维最大障碍：

### 定义

**一厢情愿思维**：一个人宁愿相信那些他希望是真的概念或事实，而不愿相信那些业已证明为真的概念或事实。

### 两种形式

#### 1. 相信内心而非真相（Truthiness）

斯蒂芬·科尔伯特2005年提出的概念：
- 相信内心直觉而非证据
- 希望什么是真的就宣布它是真的
- "我们希望事实符合我们的信念，不愿让我们的信念与事实契合"

#### 2. 奇迹式思维（Magical Thinking）

- 科学无法解释时，依赖奇迹解释因果关系
- 强大需求驱动下，否认随机性和偶发性
- 相信某人或新思想能让一切峰回路转
- 听从候选人诺言，不是因为证据而是因为渴望相信

## 价值（Value）

### 为什么重要？

1. **识别批判性思维最大障碍**：一厢情愿思维是最难克服的障碍
2. **理解思维偏见来源**：希望和恐惧构成防护墙，看不清现实
3. **自我诊断工具**：问自己"我相信这件事是因为希望它是真的，还是有确凿证据？"
4. **治疗良药**：积极主动使用批判性思维方式是一厢情愿的解药

### 与其他障碍的关系

《学会提问》识别的批判性思维障碍：
1. 正确提问带给人的不快
2. 思考过快（系统1思维）
3. 刻板印象
4. 背叛我们的思维习惯
5. 自我中心
6. **一厢情愿**：批判性思维最大的障碍

## 用法（Usage）

### 如何识别一厢情愿思维？

1. **自我提问**："我相信这件事是真的是因为我希望它是真的，还是有确凿的证据证明它是真的？"
2. **检查证据**：信念是否有可靠证据支持？
3. **寻找反例**：有没有与自己希望冲突的证据？
4. **审视愿望**：我的信念是否恰好是我希望的样子？

### 如何克服？

1. **积极主动使用批判性思维**：这是治疗一厢情愿的良药
2. **尊重好奇心**：不缺好奇心才能跨越障碍
3. **尊重批判性思维原则**：发自内心尊重各项原则
4. **承认焦虑和恐惧**：理解防护墙的来源
5. **面对冷冰冰的现实**：不逃避，不抗争

## 原理（Principle）

### 底层逻辑

**否认机制**：一厢情愿思维常常出现否认的思维模式，与事实抗争。

**防护墙**：焦虑和恐惧构成防护墙，让人看不清现实世界。

**希望驱动**：希望世间事能够更公平、更和气、更有成效，自创信念迎合虚幻世界。

**系统1思维**：一厢情愿思维是快速、无意识的系统1思维的结果。

### 例子分析

**哈利·波特例子**：
```
哈利：肯定是马尔福干的。
斯内普：你有什么证据？
哈利：我就是知道。
斯内普：你……就是……知道？
```
哈利的一厢情愿思维让他没有证据就确信结论。

**战争预测例子**：
元首宣布战争很快结束、胜利指日可待。但结果证明预测是空洞的诺言。一厢情愿思维把残酷现实抹掉了。

## 心法（Best Practices）

### 关键要点

1. **主动检查证据**：问自己"证据是什么？"
2. **区分愿望与事实**：希望是真的 ≠ 证明是真的
3. **警惕无证据确信**："我就是知道"是危险信号
4. **面对负面现实**：不把残酷现实抹掉
5. **批判性思维是解药**：积极主动使用批判性思维

### 常见表现

- 相信商品标签名副其实（因为希望如此）
- 相信战争即将胜利（因为无法承受残酷现实）
- 相信候选人诺言（因为渴望相信）
- 相信奇迹解释（因为科学无法解释）
