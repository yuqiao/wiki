# 微习惯的复利效应

## 概念

微习惯的复利效应是[[原子习惯]]的核心数学原理：每天进步1%，一年后提升约37倍（1.01^365 ≈ 37.78）。反过来，每天退步1%，一年后几乎归零（0.99^365 ≈ 0.03）。

## 数学原理

```
每天进步1%：  1.01^365 = 37.78
每天保持不变：1.00^365 = 1.00
每天退步1%：  0.99^365 = 0.03
```

**关键洞察**：时间是好习惯的朋友，是坏习惯的敌人。

## 边际收益聚合理论

英国自行车队教练戴夫·布雷斯福德提出：

> "把有关骑自行车的整个环节都分解开来，然后把每个分解出来的部分改进1%，在你把各个部分的改进都汇集起来之后，你会发现整体上的显著提高。"

英国自行车队从百年碌碌无为到奥运冠军的案例印证了这一理论。

## 原理

### 为什么微小改变有效

1. **避免触发阻力**：大改变需要大量意志力，小改变几乎不需要
2. **避开大脑防御**：本能脑和情绪脑对大改变有抵触，小改变不会触发
3. **累积效应**：微小改变日积月累形成质变

### 与[[三重大脑]]的关联

微小改变不触发本能脑的防御机制，不引起情绪脑的焦虑反应，让理智脑更容易驱动行为。

## 价值

**突破认知**：成功不在于一次巨大突破，而是微小改进的持续累积。

**降低门槛**：1%改进几乎不需要意志力，任何人都可以开始。

**长期视角**：好习惯让时间成为盟友，复利效应在后期越发明显。

## 用法

1. 设定极小的初始目标（如每天读2页书）
2. 专注于每一天的微小进步
3. 不追求完美，追求持续
4. 相信复利效应的长期威力
