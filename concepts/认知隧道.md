# 认知隧道

## 概念 (Concept)

认知隧道（Cognitive Tunneling）是指在突发情况下，大脑只盯着眼前最明显的信息，忽略全局的现象。

自动化时代尤其危险：大脑习惯被动反应，警报响起时没有"应该看哪里"的指引。

## 价值 (Value)

**理解认知隧道的重要性**

1. **识别危险信号**：知道认知隧道的存在，才能主动避免
2. **设计更好的系统**：自动化系统不应让人完全脱离
3. **培养更好的习惯**：主动构建心智模型，而不是被动等待警报

**法航447空难的教训**

2009年，法航447客机从里约飞往巴黎。皮托管结冰后自动驾驶关闭，警报响起。飞行员博宁陷入认知隧道：
- 只盯着眼前最明显的信息（速度表）
- 做出错误反应（向后拉操纵杆）
- 导致飞机失速，228人死亡

如果他什么都不做，飞机会安全飞行，皮托管内的冰也会自然融化。

## 用法 (Usage)

**如何避免认知隧道？**

1. **构建心智模型**（详见[[心智模型]]）：
   - 预演可能发生的情况
   - 知道警报响起时应该看哪里
   - 澳航32号机长在起飞前问机组："如果引擎出现故障，你应该先看哪儿？"

2. **保持主动参与**：
   - 不要完全依赖自动化
   - 定期检查系统状态
   - 保持在"驾驶状态"

3. **多视角监控**：
   - 澳航32号："如果所有人向下看，向上看"
   - 不同人关注不同方向
   - 打破单一视角

4. **训练应对突发**：
   - 模拟紧急情况
   - 在警报响起时有预案
   - 不等危机发生才思考

## 原理 (Principle)

**认知隧道的心理机制**

自动化的陷阱：
- 自动驾驶让飞行员失去主动思考的能力
- 大脑习惯被动等待信号
- 当信号出现，没有"应该看哪里"的模型
- 陷入最明显信息的隧道

大脑的注意力机制：
- 注意力有限资源
- 没有指引时，自动聚焦于最明显的信息
- 声音、灯光、数字最容易吸引注意力
- 这些可能不是最重要的信息

**主动 vs 反应性思维**

| 主动思维 | 反应性思维 |
|---------|-----------|
| 预测接下来发生什么 | 等警报响起才反应 |
| 知道应该看哪里 | 搜索最明显的信息 |
| 有心智模型 | 没有指引 |
| 避免认知隧道 | 容易陷入认知隧道 |

## 心法 (Best Practices)

**一句话总结**：认知隧道是"警报响起时盯着最明显信息"的陷阱，避免方法是主动构建心智模型。

实践要点：
- 不要等危机发生才思考应对方案
- 在脑海中有"正常状态"的图像
- 定期检查系统状态，不完全依赖自动化
- 让不同人关注不同方向

与其他概念协同：
- 与[[心智模型]]：心智模型是避免认知隧道的主要方法
- 与[[保持专注]]：认知隧道是专注的反面——错误的聚焦
- 与[[自动化陷阱]]：认知隧道是自动化的副作用
