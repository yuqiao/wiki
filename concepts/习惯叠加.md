# 习惯叠加

## 概念

习惯叠加是[[行为转变四定律]]中第一定律"让它显而易见"的具体应用方法：在现有习惯之后执行新习惯。

## 公式

```
当[当前习惯]完成后，我将[新习惯]
```

## 原理

### 为什么有效

- **利用现有神经回路**：现有习惯已是自动化行为，无需额外意志力
- **建立触发关联**：新习惯与已有习惯绑定，更容易被触发
- **降低启动成本**：不需要寻找触发时机，现有习惯就是触发点

### 与狄德罗效应

法国哲学家丹尼斯·狄德罗发现：获得一件新物品会引发连锁反应，导致更多购买。习惯叠加类似——一个习惯触发另一个。

## 用法

### 示例

| 现有习惯 | 新习惯 | 叠加公式 |
|----------|--------|----------|
| 早上倒咖啡 | 冥想一分钟 | 当我倒好咖啡后，我将冥想一分钟 |
| 晚上脱鞋 | 放好健身服 | 当我脱下工作鞋后，我将把健身服放在床边 |
| 刷牙 | 做俯卧撑十个 | 当我刷完牙后，我将做十个俯卧撑 |

### 高阶应用

多个习惯可形成叠加链：
```
当我倒好咖啡后 → 冥想一分钟 → 写日记三分钟 → 晨读五分钟
```

## 价值

**降低阻力**：利用已有习惯的自动化特性，减少新习惯启动的意志力消耗。

**建立秩序**：形成习惯链条，让一天的结构更清晰。

**即时触发**：不需要额外的提醒，现有习惯就是触发点。
