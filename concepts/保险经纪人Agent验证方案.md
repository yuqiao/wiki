# 保险经纪人Agent验证方案

> 最小可行任务：1周验证经纪人Agent是否有付费需求

---

## 概念 (Concept)

保险经纪人Agent = 帮保险经纪人管理客户、匹配产品、解答条款的AI工具。

核心功能：
- 客户管理：客户信息整理、跟进提醒、需求记录
- 产品匹配：根据客户需求快速推荐合适产品
- 条款解读：保单条款问答、重点提示风险
- 理赔协助：理赔流程指导、材料准备清单

---

## 价值 (Value)

### 经纪人的痛点

| 痛点 | 当前状态 | Agent解决方案 |
|------|---------|-------------|
| 客户分散 | 记在微信、Excel、脑子里 | 统一管理、智能提醒 |
| 产品太多 | 几百种产品记不住 | 需求→产品自动匹配 |
| 条款复杂 | 客户问条款答不专业 | 问答Agent秒回 |
| 理赔繁琐 | 材料清单记不住 | 自动生成清单+流程指导 |
| 知识更新 | 新产品法规没时间学 | 知识库自动更新推送 |

### 为什么有价值

1. **B2B付费明确**：经纪人愿意为效率工具付费（月费$50-200可接受）
2. **市场规模大**：中国保险经纪人约200万，头部经纪人年收入百万+
3. **复购率高**：效率工具一旦用上，很难停
4. **可扩展**：从经纪人→保险公司→消费者

---

## 用法 (Usage)

### 最小可行任务（1周验证）

```
Day 1-2：调研痛点
- 找3-5个保险经纪人访谈
- 问：你最大的效率痛点是什么？
- 问：你愿意为解决这个痛点付多少钱？
- 问：你现在用什么工具管理客户？

Day 3-4：设计原型
- 选择1个痛点（如条款解读）
- 设计Agent架构：RAG + 条款知识库 + 问答接口
- 画产品原型图（微信小程序/Web）

Day 5-7：验证原型
- 用Claude Code快速搭建原型
- 给经纪人试用，收集反馈
- 问：这个原型解决你的问题了吗？
- 问：你会付费吗？多少钱？
```

### 技术架构（简化版）

```
用户输入（条款问题）
    ↓
Agent入口（Claude/DeepSeek）
    ↓
RAG检索（条款知识库）
    ↓
生成回答（专业解读）
    ↓
输出（微信/Web）
```

核心组件：
- **知识库**：主流保险公司条款PDF（先收集10-20个）
- **RAG引擎**：向量检索+语义匹配
- **LLM**：Claude/DeepSeek（条款解读需要准确性）
- **接口**：微信小程序（经纪人都在用微信）

## 原理 (Principle)

### 为什么有效

1. **RAG解决准确性**：条款解读不能乱说，RAG确保答案来自真实条款
2. **Agent解决效率**：经纪人每天问条款几十次，Agent秒回省时
3. **微信入口降低门槛**：经纪人习惯微信，无需安装新App

### 商业模式

```
免费版：
- 条款问答（限次数）
- 产品查询

付费版 $99/月：
- 无限条款问答
- 客户管理（100客户）
- 产品智能匹配
- 理赔流程指导

专业版 $299/月：
- 无限客户管理
- 团队协作（5人）
- 数据分析报表
- 优先客服支持
```

## 心法 (Best Practices)

### 验证心法

1. **先找人，再做产品**：没有愿意付费的经纪人，产品无用
2. **先解决1个痛点**：不要做全功能，先做条款问答验证
3. **原型要快**：Claude Code 1周搭出原型，不要花几个月
4. **反馈要真实**：经纪人说"可能有用"=没用，说"我要付费"才有用

### 避坑指南

1. **不要做大平台**：先做小工具，验证成功再扩展
2. **不要免费给所有人**：免费用户不会告诉你真实需求
3. **不要完美主义**：原型丑没关系，能验证就行
4. **不要闭门造车**：每2天和经纪人交流一次

## 下一步行动

### 本周任务（Day 1-7）

```
Day 1（今天）：找经纪人联系方式
- 朋友圈/微信群找保险经纪人
- 目标：找到3-5个愿意访谈的经纪人

Day 2：访谈痛点
- 问：最大的效率痛点是什么？
- 问：条款解读需要多少时间？
- 问：愿意付多少钱？

Day 3-4：收集条款数据
- 下载主流保险公司条款PDF（10-20个）
- 建立简单知识库

Day 5-6：搭建原型
- Claude Code + RAG
- 简单问答接口

Day 7：经纪人试用+反馈
- 给经纪人试用原型
- 收集：解决问题了吗？愿意付费吗？
```

### 成功标准

- **验证成功**：至少2个经纪人说"我要付费"
- **验证失败**：经纪人说"可能有用"或"不付费"
- **pivot**：如果条款问答无需求，换方向（理赔协助/产品匹配）
