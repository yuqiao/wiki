# 番茄工作法

## Concept
一种时间管理技术，将工作分割为25分钟的专注时段（番茄钟），每段之间短暂休息。核心是**有意识地控制注意力**，而非单纯追求效率。

## Value
- **降低启动阻力** — 只需专注25分钟，心理负担小
- **防止疲劳积累** — 定时休息维持精力
- **量化专注时间** — 一天完成了几个番茄钟一目了然
- **打断保护** — 外部干扰记录为"打断"，延后处理

## Usage

### 基本流程
1. 选择一项任务
2. 设定定时器 25 分钟
3. 专注工作直到铃响
4. 短休息 5 分钟
5. 每 4 个番茄钟后长休息 15-30 分钟

### 规则
- 番茄钟**不可分割** — 被打断则作废，重新开始
- 番茄钟内**不处理其他事** — 记录干扰，稍后处理
- 休息时**不继续工作** — 真正放松，喝水、走动

### 工具推荐
- **手机**: Forest、专注清单、番茄土豆
- **电脑**: Pomotodo、Tomato Timer（网页）
- **物理**: 厨房计时器、Time Timer（可视化）

## Principle
### 为什么是25分钟？
- 足够短，降低拖延心理
- 足够长，进入深度工作
- 人类专注力自然波动周期约 20-30 分钟

### 休息为什么重要？
- 大脑需要**默认模式网络**激活来整合信息
- 持续专注导致认知资源耗尽，效率下降
- 短休息让下一轮专注恢复到高水平

## Best Practices

### 🎯 进阶技巧
| 技巧 | 说明 |
|------|------|
| **任务拆分** | 超过4个番茄钟的任务要拆分 |
| **任务合并** | 不足1个番茄钟的小事合并处理 |
| **预测与复盘** | 预估需要几个番茄钟，完成后对比 |
| **打断记录** | 每次被打断记下来，分析干扰源 |

### ⚠️ 常见误区
- ❌ 休息时继续思考工作 — 应彻底放松
- ❌ 番茄钟中途停下来处理"紧急"事 — 记录后延后
- ❌ 强行凑够25分钟 — 任务完成就结束
- ❌ 忽略长休息 — 每4个番茄必须长休息

### 🔧 灵活调整
- **专注时长**: 可调整为 15/30/45 分钟
- **休息时长**: 短休 3-10 分钟，长休 20-40 分钟
- **找到自己的节奏**: 记录一周数据，优化参数
