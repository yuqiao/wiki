# 可信度加权决策

## What — 是什么

可信度加权决策是[[瑞·达利欧]]在[[原则]]中提出的决策方法：对不同人的观点进行加权，根据其可信度（过往成功记录）给予不同权重，然后选择最优观点。这是[[创意择优]]的核心机制。

## Why — 为什么重要

1. **超越个人局限**: 单个人总有思维盲点，加权决策融合多视角
2. **降低错误概率**: 高可信度观点者过往成功率高，更可能正确
3. **避免群体陷阱**: 不是简单投票，而是加权投票
4. **客观化决策**: 用数据而非情绪做决定

## How — 如何实施

### 确定可信度

可信度基于过往成功记录：
- 在相关领域有多少次成功预测/决策
- 是否能清晰解释其逻辑
- 是否愿意接受挑战和质疑

**高可信度者特征**:
- 在该领域有反复成功经验
- 能逻辑清晰地解释观点
- 承认自己可能有错误
- 真诚关心结果而非面子

### 权重分配

- 不是所有人权重相同
- 过往成功次数多 → 权重高
- 能解释逻辑 → 权重加分
- 有利害关系 → 权重减分

### 决策流程

1. 收集所有人的观点
2. 让每人解释其逻辑
3. 评估每人的可信度
4. 对观点进行加权
5. 选择加权后的最优观点

### 实施要点

- **不追求共识**: 不需要所有人同意
- **允许分歧**: 分歧是发现真相的机会
- **透明权重**: 所有人知道权重如何计算
- **持续更新**: 根据新结果更新可信度

## 核心转变

达利欧的关键转变：
```
从 "我知道我是对的"
到 "我怎么知道我是对的"
```

这个转变让他：
- 变得谦逊，平衡勇敢
- 从自己和别人的视角同时看问题
- 看到更多维度

## 与简单投票的区别

| 特性 | 简单投票 | 可信度加权 |
|------|----------|------------|
| 权重 | 人人均等 | 根据成功记录加权 |
| 依据 | 数量 | 质量 + 数量 |
| 专家意见 | 与新手相同 | 专家权重更高 |
| 情绪 | 可能主导 | 尽量排除 |

## 在桥水的实践

桥水公司将这一方法系统化：
- 建立每个人的"可信度矩阵"
- 记录每次决策和结果
- 用算法计算加权结果
- 计算机辅助决策，排除情绪

达利欧同时运行两套决策体系：
- 头脑中的决策
- 计算机中的决策

发现计算机能做出更好的决策，因为：
- 处理信息更多
- 不带感情
- 速度更快

## 适用场景

- 团队战略决策
- 投资决策
- 产品方向选择
- 人事任命
- 危机应对

**不适用场景**:
- 个人生活小事（如晚餐吃什么）
- 紧急情况（需快速反应）
- 纯执行性决策

## 个人应用

对于个人：
- 记录自己的决策和结果
- 找出自己高可信度的领域
- 在低可信度领域寻求他人意见
- 对他人意见给予适当权重
