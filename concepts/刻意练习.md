# 刻意练习

## 概念 (Concept)

**刻意练习（Deliberate Practice）**：有目的、有反馈、专注的训练方法。需要在无干扰状态下进行，专注于提升特定技能。

由心理学家[[K·安德斯·艾利克森]]（K. Anders Ericsson）提出。

## 价值 (Value)

刻意练习是技能习得的核心方法：
- 解释专家与普通人的差距
- 揭示天才背后的训练量
- 提供可操作的提升路径

刻意练习与[[深度工作]]高度重叠：都需要无干扰状态、全情投入、持续反馈。

## 用法 (Usage)

### 刻意练习要素

1. **明确目标**：知道要提升什么
2. **专注投入**：全神贯注于练习
3. **即时反馈**：知道表现如何
4. **重复改进**：持续调整优化

### 刻意练习的应用

- **音乐训练**：乐器练习
- **体育训练**：技术动作
- **写作训练**：有目的地写作
- **编程训练**：项目练习

### 与深度工作的关系

刻意练习需要在深度工作状态下进行：
- 无干扰环境
- 高度专注
- 持续反馈

## 原理 (Principle)

### 一万小时定律

艾利克森研究发现：
- 专家需要约一万小时刻意练习
- 简单重复不等于刻意练习
- 只有刻意练习才能提升

### 神经科学解释

刻意练习改变大脑：
- 髓磷脂包裹神经元
- 强化神经连接
- 固化技能路径

高度专注使少突细胞在神经元周围包裹髓磷脂，加速信号传输。

### 四个认知阶段

技能习得的阶段：
1. 无意识无能：不知道自己不会
2. 有意识无能：知道自己不会
3. 有意识有能：有意识地做
4. 无意识有能：自动化执行

刻意练习帮助从第2阶段到第3阶段。

## 心法 (Best Practices)

### 专注练习

- 练习时全神贯注
- 消除干扰
- 每次只练一个点

### 即时反馈

- 获得教练或老师指导
- 录制自己的表现
- 与标准对比

### 突破舒适区

- 选择略超能力的挑战
- 金发姑娘准则：不太难不太易
- 持续挑战新高度

### 时间管理

- 刻意练习有上限：约4小时/天
- 高质量练习优于长时间
- 休息与练习同样重要
