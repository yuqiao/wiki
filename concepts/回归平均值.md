# 回归平均值

**回归平均值**（Regression to the Mean）是统计学现象：极端表现之后，倾向于回归正常水平——不是因为任何干预，而是统计规律。第17章专题讨论。

## 概念

回归平均值的核心：
- 极端表现 → 往往回归正常
- 不是因果关系
- 是统计规律

例子：
- 飞行员一次训练成绩很差 → 下次往往好转
- 并不是因为教练批评或鼓励
- 而是回归平均值

人类直觉误解：
- 极端差 → 认为需要干预才能好转
- 极端好 → 认为会持续好
- 实际是回归平均值

## 经典案例

### 飞行员训练

以色列空军发现：
- 批评差成绩飞行员 → 下次成绩好转
- 好成绩飞行员 → 下次成绩下滑
- 结论：批评有效，表扬有害

卡尼曼指出：这是回归平均值！
- 差成绩往往是异常低 → 下次回归正常
- 好成绩往往是异常高 → 下次回归正常
- 与批评表扬无关

### 体育预测

- 球员某赛季表现极佳 → 下赛季往往下滑
- 球员某赛季表现极差 → 下赛季往往好转
- 不是能力变化，而是回归平均值

### 股市波动

- 极端涨跌后 → 往往回归正常波动
- 不是技术分析有效
- 而是回归平均值

### 学生成绩

- 某次考试极端好或差 → 下次往往回归正常
- 不是教学干预效果
- 而是回归平均值

## 回归平均值的机制

### 1. 随机波动

- 表现=能力+运气
- 运气随机波动
- 极端表现时运气极端
- 下次运气回归正常 → 表现回归正常

### 2. 统计规律

- 不需要因果解释
- 极端偏离平均值 → 偏离减小
- 自然趋向平均值

## 人类直觉的误解

### 1. 强行因果解释

- 极端差 →好转 → 认为是干预有效
- 极端好 →下滑 → 认为是放松懈怠
- 强行找原因，忽略回归平均值

### 2. 过度信任极端表现

- 极端好 → 认为会持续
- 极端差 → 认为会恶化
- 忽略回归趋势

### 3. 错误归因

- 将回归平均值效果归因于干预
- 虚假因果关系
- 错误学习

## 实践启示

### 评估干预效果

- 不要轻易将回归平均值归因于干预
- 对比对照组
- 区分回归效应和干预效果

### 预测未来

- 极端表现不可持续
- 预测时考虑回归平均值
- 不要过度信任极端数据

### 避免"迷信"

- "批评后好转"不一定是批评有效
- "奖励后下滑"不一定是奖励有害
- 考虑回归平均值

### 体育投资

- 不要过度信任极端赛季表现
- 预测时回归正常水平
- 极端表现不等于能力提升
