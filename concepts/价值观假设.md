# 价值观假设

论证中隐含的价值偏好。在价值冲突中选择某一方的未明说偏好，是论证的隐藏骨架。

## 概念（Concept）

[[学会提问]]第5章核心概念：

### 定义

**价值观假设**：在价值冲突中，立论者选择某一方的隐含偏好。

### 与描述性假设的区别

| 维度 | 价值观假设 | 描述性假设 |
|------|-----------|-----------|
| 类型 | 关于"应该" | 关于"是什么" |
| 内容 | 价值偏好 | 世界观 |
| 来源 | 价值冲突选择 | 对世界的认知 |
| 例子 | 自由 > 秩序 | 人是自私的 |

## 价值（Value）

### 为什么重要？

1. **论证的隐藏骨架**：价值观假设是论证的核心支撑
2. **理解论证立场**：找到价值观假设才能理解为什么持某一立场
3. **识别价值冲突**：理解不同观点背后的价值分歧
4. **深度评价论证**：不只看理由，还要看隐含的价值假设

### 典型价值观冲突

| 价值观A | 价值观B | 冲突情境 |
|--------|--------|---------|
| 个人自由 | 社会秩序 | 疫情管控 |
| 效率 | 公平 | 资源分配 |
| 竞争 | 合作 | 教育评价 |
| 短期利益 | 长期利益 | 环保政策 |
| 个人责任 | 社会责任 | 贫困救助 |

## 用法（Usage）

### 如何寻找价值观假设？

1. **寻找价值冲突**：论证涉及哪些对立价值观？
2. **判断价值倾向**：立论者选择哪一方？
3. **检查立论者背景**：背景常暗示价值观偏好
4. **分析后果偏好**：立论者希望什么后果发生？

### 寻找线索

#### 1. 立论者背景

- 职业、身份、组织 affiliation
- 过往言论和行为
- 既得利益分析

#### 2. 可能发生的后果

- 论证支持什么后果？
- 后果偏好暗示价值倾向

#### 3. 类似论证类比

- 同类论证持什么价值观？
- 是否形成价值偏好模式？

## 原理（Principle）

### 底层逻辑

**隐含性**：价值观假设通常不明说，需要推理发现。

**价值冲突**：假设存在于价值冲突情境中，是选择而非共识。

**论证骨架**：理由 + 价值观假设 → 结论

**互相对立**：不同观点的价值观假设可能对立。

### 与论证的关系

论证结构：
```
理由 → 结论
↑
价值观假设（隐含）
```

价值观假设决定理由指向哪个结论。

## 心法（Best Practices）

### 关键要点

1. **价值冲突是关键**：没有冲突就没有价值观假设
2. **后果分析**：立论者希望什么后果？
3. **背景线索**：立论者身份常暗示价值偏好
4. **对比论证**：类似论证的价值模式
5. **假设不等于错误**：价值观假设不一定错误，只是需要识别

### 常见误区

- 忽略价值观假设：只看理由不看隐藏偏好
- 价值观假设等于偏见：假设不等于错误
- 强加自己的价值观：用自己价值观评判他人
- 忽略价值冲突情境：没有冲突就没有假设
