# 下一步行动

## What — 是什么

下一步行动是[[戴维·艾伦]]在[[搞定]]方法论中提出的核心概念：**推动完成某个事项的下一步有形及可见的行为。它非常具体，足以让你明白其实施时间、适用工具以及可能的执行情形。**

这是 GTD 方法的核心技巧——将模糊的项目转化为具体可执行的行动。

## Why — 为什么重要

1. **消除模糊**: 模糊的事项无法执行，具体行动才能推进
2. **降低阻力**: 明确第一步让启动更容易
3. **释放压力**: 知道第一步是什么，心理负担减轻
4. **克服拖延**: 不确定下一步是拖延的主要原因
5. **提高效率**: 清晰行动比模糊任务执行更快

## How — 如何确定

### 定义标准

一个好的下一步行动必须：
- **有形可见**: 可以在物理世界中执行
- **具体明确**: 清楚知道要做什么
- **单一行为**: 不是复合任务
- **情境清晰**: 知道需要什么工具、在哪里执行

### 确定方法

对每个项目或任务问：
- "我要完成这件事，下一步具体要做什么？"

示例转换：

| 模糊任务 | 下一步行动 |
|---------|-----------|
| "写报告" | "在电脑上打开报告模板，填写第一部分" |
| "联系客户" | "给张经理打电话，询问项目进度" |
| "准备会议" | "创建会议议程文档，列出讨论事项" |
| "修车" | "打电话给维修店预约时间" |
| "学习编程" | "打开Python教程第一章，阅读前10页" |

### 验证方法

问自己：
- 我现在能执行这个行动吗？（情境检查）
- 我清楚知道怎么做吗？（明确性检查）
- 这是一个单一行为吗？（原子性检查）

如果不确定，继续细化直到满足标准。

## 心理学依据

### 执行意图理论

心理学家 Peter Gollwitzer 提出"执行意图"概念：
- "如果情境X出现，我就执行行为Y"
- 具体的行动描述比模糊意图更可能执行

下一步行动本质上是定义执行意图。

### 认知负荷理论

模糊任务需要持续认知加工：
- "我要写报告" → 每次想起都要思考"怎么写？写什么？"
- "打开模板填写第一部分" → 一想起就知道怎么做

具体行动减少认知加工需求。

### 计划谬误

人们低估复杂任务的时间。分解为下一步行动：
- 揭示真实工作量
- 让计划更现实
- 提供进度反馈

## 在 GTD 中的位置

### 工作流程中的应用

在 GTD 五步工作流程中，确定下一步行动发生在**理清阶段**：

```
收集 → 理清 → 组织整理 → 回顾 → 执行
         ↑
      "下一步行动是什么？"
```

### 存储位置

确定下一步行动后，根据特征存储：

| 下一步行动特征 | 存储位置 |
|--------------|---------|
| 有刚性时间要求 | 日程表 |
| 需要特定情境 | 情境清单（电话、电脑、外出等） |
| 委派他人 | 等待清单 |
| 超过两分钟 | 行动清单 |
| 两分钟内 | 立即执行 |

## 常见误区

### 误区1：把项目当作下一步行动

错误示例：
- 下一步行动："写年度报告"
- 这实际是一个项目（多步骤）

正确做法：
- 下一步行动："打开报告文档，列出章节大纲"

### 误区2：过于笼统

错误示例：
- 下一步行动："思考项目方案"
- 这不够具体，无法直接执行

正确做法：
- 下一步行动："在白板上画出项目流程图"

### 误区3：复合行动

错误示例：
- 下一步行动："打电话并发邮件"
- 这是两个行动

正确做法：
- 拆分为两个下一步行动

### 误区4：忽略情境

错误示例：
- 下一步行动："去银行开户"
- 但现在没有时间外出

正确做法：
- 下一步行动："查银行网点营业时间"（当前可执行）
- 下一步行动："去银行开户"（外出清单）

- [[悬而未决]] — 确定下一步行动消除悬而未决
