# 浮浅工作

## 概念 (Concept)

**浮浅工作（Shallow Work）**：对认知要求不高的事务性任务，往往在受到干扰的情况下开展。此类工作通常不会为世界创造太多新价值，且容易复制。

浮浅工作是[[深度工作]]的对立概念。

## 价值 (Value)

### 浮浅工作的局限

浮浅工作的问题：
- **低价值创造**：不会产出突破性成果
- **易于复制**：可被他人或机器替代
- **碎片化注意力**：削弱深度工作能力
- **占用时间**：挤占深度工作时间

### 为什么人们倾向于浮浅工作？

1. **最小阻力原则**：浮浅工作更容易执行
2. **忙碌代表生产能力**：浮浅工作创造"忙碌感"
3. **即时反馈**：快速完成任务获得满足
4. **社交需求**：回复邮件、消息等社交回报

## 用法 (Usage)

### 识别浮浅工作

判断标准：
- 能否在干扰状态下完成？
- 是否需要高强度认知？
- 是否创造独特价值？
- 能否被轻易复制？

### 管理浮浅工作

管理策略：
1. **定量分析**：计算每项活动的深度
2. **时间预算**：限制浮浅工作时间
3. **批量处理**：集中处理浮浅任务
4. **委托外包**：交给他人或机器

### 向老板申请浮浅工作预算

与上司沟通：
- 明确浮浅工作占比
- 申请深度工作时间保护
- 争取减少不必要会议

## 原理 (Principle)

### 浮浅工作与注意力残留

浮浅工作频繁切换导致[[注意力残留]]累积，严重影响深度工作时间的工作质量。

### 浮浅工作陷阱

浮浅工作的隐性代价：
- 感觉忙碌但无产出
- 深度工作能力退化
- 职业发展停滞

### 必要的浮浅工作

某些浮浅工作是必要的：
- 行政事务
- 沟通协调
- 信息传递

关键是控制占比和管理方式。

## 心法 (Best Practices)

### 摒弃浮浅

- 一天的每一分钟都要做好计划
- 定量分析每一项活动的深度
- 5点半之前结束工作
- 变得不容易联系到

### 批量处理

将浮浅工作集中处理：
- 固定时间处理邮件
- 批量回复消息
- 集中处理行政事务

### 减少浮浅

主动减少：
- 拒绝不必要会议
- 减少社交媒体时间
- 简化工作流程
