# 史特金定律

**史特金定律**（Sturgeon's Law）是[[丹尼尔·丹尼特]]在[[直觉泵和其他思考工具]]中介绍的质量过滤器。核心：**任何事物的90%都是垃圾。** 不要浪费时间批评垃圾，只关注那10%的精品。

## 概念

### 起源

由科幻作家西奥多·史特金（ Theodore Sturgeon）提出，回应人们对科幻小说的批评："科幻小说都是垃圾。"

史特金的回应：
> "是的，90%的科幻小说确实是垃圾。但这个比例对任何领域都成立——90%的电影、90%的书、90%的评论都是垃圾。问题是：你为什么不关注那10%的精品？"

### 定律的完整表述

```
任何领域的事物：
─────────────────────
   90%  → 垃圾/平庸
    ↓
   10%  → 精品/有价值
─────────────────────

结论：批评垃圾浪费时间，关注那10%
```

### 三层含义

| 层次 | 含义 | 应用 |
|------|------|------|
| 第一层 | 统计事实 | 任何领域确实90%是平庸之作 |
| 第二层 | 选择策略 | 不浪费时间在垃圾上 |
| 第三层 | 批评伦理 | 批评精品才有价值，批评垃圾没意义 |

## 价值

| 维度 | 价值说明 |
|------|---------|
| 时间保护 | 防止被垃圾消耗精力 |
| 批评聚焦 | 只批评值得批评的东西 |
| 心态调整 | 不对"垃圾比例"感到惊讶 |
| 标杆设定 | 以10%精品为标准 |

**丹尼特的补充**：

> "不要浪费时间和才华批评垃圾。批评垃圾本身就是垃圾行为。你的批评只有在面对值得批评的东西时才有价值。"

### 与帕累托原则的区别

| 帕累托原则（80/20） | 史特金定律（90/10） |
|---------------------|---------------------|
| 80%结果来自20%原因 | 90%是垃圾，10%是精品 |
| 关注高产出部分 | 关注高质量部分 |
| 效率导向 | 质量导向 |
| 可量化 | 定性判断 |

史特金定律更"残酷"——它说的是质量，不是产出。

## 用法

### 史特金定律的应用模板

**遇到新领域时**：

```markdown
## 这个领域的10%精品是什么？
- [列出公认的经典/标杆]
- [找出被专业人士推崇的作品]

## 我如何识别那10%？
- [专业评审标准]
- [历史筛选结果]
- [跨领域推荐]

## 我如何避免被90%垃圾消耗？
- [设定质量门槛]
- [信任可靠来源]
- [快速淘汰机制]
```

### 识别精品的信号

| 信号 | 说明 |
|------|------|
| 时间筛选 | 经过时间考验仍被讨论 |
| 专业认可 | 领域内专业人士推荐 |
| 跨领域引用 | 其他领域的专家也引用 |
| 深度讨论 | 引发深入而非表面的讨论 |
| 改变实践 | 改变了人们的行为方式 |

### 识别垃圾的信号

| 信号 | 说明 |
|------|------|
| 热度驱动 | 只有热度，没有深度 |
| 快速遗忘 | 几个月后没人记得 |
| 重复平庸 | 没有新意，只是模仿 |
| 情绪操控 | 激发情绪而非思考 |
| 流量导向 | 明显为流量而非价值创作 |

## 原理

### 为什么90%是垃圾？

```
创作门槛降低
    ↓
大量低质量作品涌入
    ↓
注意力市场竞争
    ↓
垃圾靠数量取胜
    ↓
精品靠质量筛选
```

**进化视角**：

- 任何领域刚开始都是"探索期"
- 大量尝试 → 少数成功 → 90%失败
- 这不是问题，这是创新的代价

**信息爆炸时代**：

- 互联网让创作门槛降到零
- 信息量爆炸 → 噪音比例上升
- 史特金定律更成立：可能从90%变成99%

### 史特金定律的深层逻辑

```
为什么批评垃圾没价值？
─────────────────────
批评垃圾：
- 对象本身没价值 → 批评也不产生价值
- 垃圾创作者不在乎 → 批评无效
- 读者不会去看 → 批评没受众
→ 批评本身变成垃圾

批评精品：
- 对象有价值 → 批评可能增值
- 创作者认真 → 批评可能改进
- 读者会关注 → 批评有受众
→ 批评本身可能成为精品
─────────────────────
```

## 心法

### 史特金定律的实践心法

1. **"这是10%还是90%？"**
   - 遇到任何作品先问这个问题
   - 如果是90%，快速淘汰
   - 如果疑似10%，深入评估

2. **"我为什么在批评垃圾？"**
   - 反思批评动机
   - 如果只是为了发泄，停止
   - 如果是为了帮助那10%，继续

3. **"我自己的作品是10%还是90%？"**
   - 自我审视更重要
   - 问：我的作品值得被批评吗？
   - 如果是90%，先改进自己

4. **"如何找到那10%？"**
   - 建立可靠的筛选机制
   - 信任专业人士的推荐
   - 关注历史筛选结果

### 常见误用

| 误用 | 表现 | 修正 |
|------|------|------|
| 否定一切 | "反正90%是垃圾" | 专注于找到10% |
| 优越感 | "我看的东西都是精品" | 检验：真的符合10%标准吗？ |
| 懒惰筛选 | "懒得找精品" | 精品值得投入筛选精力 |
| 过度苛刻 | "这不是10%，放弃" | 可能错过成长中的精品 |

### 与其他工具的协同

```
史特金定律 → 决定是否值得投入
    ↓
如果值得 → 拉波波特法则 → 理解对方
    ↓
然后 → 归谬法 → 压力测试
    ↓
最后 → 犯错儿 → 从错误中学习
```

**协同应用顺序**：

```
遇到一个观点/作品
    ↓
Step 1: 史特金定律筛选
        → 是10%精品吗？
        → 如果不是，放弃
    ↓
Step 2: 拉波波特法则理解
        → 我能重述到对方满意吗？
    ↓
Step 3: 归谬法检验
        → 推到极端会怎样？
    ↓
Step 4: 犯错儿分析
        → 这是个好错儿吗？能学到什么？
```

## 实际应用示例

### 书籍筛选

```
领域：个人成长/效率类书籍
─────────────────────
90%垃圾信号：
- 标题夸张（"30天改变人生"）
- 内容重复（都是早起、冥想、阅读）
- 没有原创框架
- 热度高但专业人不说

10%精品信号：
- 经过20年仍在讨论（《思考快与慢》）
- 专业人士反复引用（《原则》）
- 有原创理论框架（《搞定》GTD系统）
- 改变了行业实践

筛选策略：
- 看专业推荐而非热度
- 看时间筛选而非当下销量
- 看理论贡献而非实用性宣传
─────────────────────
```

### 内容消费

```
社交媒体内容
─────────────────────
识别垃圾：
- 热点追逐型内容
- 情绪煽动型标题
- 无深度讨论
- 纯流量导向

识别精品：
- 有原创观点
- 引发深度讨论
- 专业人士参与
- 有长期价值

策略：
- 快速滑过90%
- 深度阅读10%
- 不为垃圾评论
─────────────────────
```

### 批评选择

```
观点批评
─────────────────────
不值得批评（90%）：
- 明显逻辑错误
- 情绪化表达
- 没有论证过程
- 无学习价值

值得批评（10%）：
- 有逻辑连贯性
- 有认真论证
- 可能是好错儿
- 批评可能改进讨论

丹尼特的警告：
"批评垃圾本身就是垃圾行为"
─────────────────────
```
