# 光环效应

**光环效应**（Halo Effect）是人类判断的核心偏见：某一方面的印象影响整体评价——好的一面让整体看起来好，坏的一面让整体看起来坏。

## 概念

光环效应的核心：
- 第一印象影响后续判断
- 好的一面 → 整体好
- 坏的一面 → 整体坏

例子：
- 演讲者外表自信 → 观众认为他内容也好
- 公司成功 → 认为其战略、文化、领导都好
- 人长得好看 → 认为性格也好

卡尼曼序言中的描述：
> "一个潇洒自信的演讲者刚踏上舞台，观众往往就会对其大加赞赏，他可能并没有那么优秀，但这好评如潮的结果在他踏上舞台的一刹那便可预见。这种先入为主的情形是有据可依的，即光环效应。"

## 光环效应的机制

### 1. 第一印象

- 第一个特征形成整体印象
- 后续信息被这个印象过滤
- 一致性偏好：让后续信息符合第一印象

### 2. 系统1的连贯性需求

- [[系统1]]追求连贯性
- 好的一面 → 构建好的故事
- 坏的一面 → 构建坏的故事
- 不接受矛盾信息

### 3. 信息过滤

- 光环效应过滤后续信息
- 支持光环的信息被接受
- 反驳光环的信息被忽略或扭曲

## 光环效应的案例

### 演讲者效应

- 演讲者自信踏上舞台 → 好评
- 实际内容可能平庸
- 但光环效应让内容看起来也好

### 企业评价

- 成功企业 → 战略、文化、领导都被认为好
- 失败企业 → 战略、文化、领导都被认为差
- 实际可能只有运气差异

### 人物评价

- 成功者 → 聪明、勤奋、正直
- 失败者 → 懒惰、愚蠢、不道德
- 同一人，成败不同，评价不同

### 产品评价

- 品牌形象好 → 产品各维度评价高
- 品牌形象差 → 产品各维度评价低
- 实际产品可能相同

## 光环效应的影响

### 1. 判断失真

- 某一方面印象主导整体
- 其他维度评价失真
- 整体判断不客观

### 2. 成功归因错误

- 成功光环 → 归因于能力、战略
- 实际可能是运气
- 学习错误的"成功经验"

### 3. 失败归因错误

- 失败光环 → 归因于愚蠢、懒惰
- 实际可能是环境运气
- 不公正的指责

### 4. 预测失误

- 光环效应让人相信"成功者"会继续成功
- 实际成功不保证未来成功
- 过度信任成功者

## 对抗光环效应

### 分离维度

- 将评价拆分到不同维度
- 独立评估每个维度
- 不让某一维度主导整体

### 打破第一印象

- 主动寻找反驳第一印象的证据
- 问自己"有没有反例"
- 接受矛盾信息

### 系统2审查

- 光环效应是系统1产物
- 重要评价时启动系统2
- 逐维度客观评估
