# 六层次视野

## What — 是什么

六层次视野是[[戴维·艾伦]]在[[搞定]]方法论中的战略框架：**我们以个人和/或组织形式做出的不同层次的承诺，以及拥有的想法。从最具体的行动到最高层次的目的和原则。**

这提供了一个从微观到宏观的完整视野体系，帮助在不同层面做出决策。

## Why — 为什么重要

1. **多层次决策**: 不同问题需要不同视野
2. **战略一致性**: 确保行动与目标一致
3. **方向指引**: 避免迷失在细节中
4. **优先级判断**: 从更高视野评估重要性
5. **完整视角**: 微观行动和宏观愿景的统一

## 六个层次详解

### 地面视野：下一步行动

**内容**: 我们在有形和可见层面处理的事项

**示例**:
- 打电话、发邮件
- 处理文档
- 与某人会面
- 完成特定任务

**管理工具**:
- 行动清单
- 日程表
- 情境清单

**关注点**: 当前能做什么

### 1楼视野：项目

**内容**: 我们承诺在一年内完成、要求采取一个以上具体步骤的任何事项

**示例**:
- 修理刹车灯
- 重组西部区域办事处
- 完成某项报告
- 策划某次会议

**管理工具**:
- 项目清单
- 项目支持资料

**关注点**: 什么需要完成

**重要性**: "每周回顾"的关键待办事项

### 2楼视野：重点及责任范围

**内容**: 我们需要维持的生活和工作内容，旨在确保我们自身和我们企业的稳定和健康

**示例**:
- 健康、财务
- 客户服务、战略规划
- 家庭、事业
- 个人成长

**管理工具**:
- 责任领域清单
- 检查清单

**关注点**: 哪些领域需要维护

**特点**: 无明确终点，持续维护

### 3楼视野：目标

**内容**: 拟实现的中期至长期结果（通常在3~24个月内）

**示例**:
- 完成收购某公司
- 创建可盈利的在线课程
- 完成孩子的大学规划
- 达成某项业绩指标

**管理工具**:
- 目标清单
- 战略计划

**关注点**: 什么结果要达成

**特点**: 有明确终点和时间框架

### 4楼视野：展望

**内容**: 长期预期结果；理想的完胜方案

**示例**:
- 出版回忆录
- 实现公司上市
- 在某地购置度假屋
- 达成人生愿景

**管理工具**:
- 愿景文档
- 人生规划

**关注点**: 长期方向是什么

**特点**: 可能数年内持续努力

### 5楼视野：目的和原则

**内容**: 一个人或一个企业的终极目标、存在理由和核心价值

**示例**:
- "为绝大多数市民持续提供最好的商品，服务于社区发展"
- "帮助人们过上更有意义的生活"
- 个人核心价值观

**管理工具**:
- 使命宣言
- 价值观清单
- 原则文档

**关注点**: 为什么存在，核心信念是什么

**特点**: 相对稳定，是最高指引

## 层次关系图

```
┌─────────────────────────────────────┐
│  5楼：目的和原则（Why）             │
│    ↓ 指引                           │
│  4楼：展望（长期愿景）              │
│    ↓ 驱动                           │
│  3楼：目标（中期结果）              │
│    ↓ 定义                           │
│  2楼：重点及责任范围（维护领域）    │
│    ↓ 包含                           │
│  1楼：项目（具体产出）              │
│    ↓ 组成                           │
│  地面：下一步行动（具体执行）       │
└─────────────────────────────────────┘
```

**向上看**: 行动是否符合更高目标
**向下看**: 目标如何分解为行动

## 使用方法

### 日常决策

主要使用地面视野和1楼视野：
- "我现在能做什么？"
- "哪个项目需要推进？"

### 定期回顾

每周回顾检视1-2楼：
- 项目进展如何
- 责任领域是否平衡

### 战略规划

季度或年度回顾检视3-5楼：
- 目标是否达成
- 愿景是否接近
- 原则是否坚持

### 遇困惑时

向上看更高视野：
- "这件事对我的目标有意义吗？"
- "这与我的价值观一致吗？"

### 遇迷失时

向下看具体行动：
- "下一步具体要做什么？"

## 与决策的关系

选择行动的四标准法中，**重要性**来自更高视野的判断：

```
重要性 ← 目标（3楼）
        ← 重点范围（2楼）
        ← 目的和原则（5楼）
```

知道"为什么"才能判断"什么重要"。

## 常见问题

### 问题1：只关注地面

只处理具体行动，忽视更高视野 → 迷失方向

**解决**: 定期向上看，检视目标和愿景

### 问题2：只关注高层

只谈愿景目标，不落实到行动 → 空谈

**解决**: 向下分解，确定下一步行动

### 问题3：视野断层

高层愿景与日常行动不连接 → 战略执行失败

**解决**: 每层都要连接，行动服务于目标

### 问题4：层次混乱

不同层次问题用错误视野处理 → 无效

**解决**: 识别问题层次，用相应视野处理

## 与其他框架的比较

| GTD六层次 | 其他框架 |
|----------|---------|
| 目的和原则 | 核心价值观 |
| 展望 | 人生愿景 |
| 目标 | OKR目标 |
| 重点范围 | 责任矩阵 |
| 项目 | 项目列表 |
| 下一步行动 | 待办清单 |

GTD 的优势：完整整合所有层次，形成统一体系。
