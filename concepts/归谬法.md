# 归谬法

**归谬法**（Reductio ad Absurdum）是[[丹尼尔·丹尼特]]在[[直觉泵和其他思考工具]]中介绍的通用思考工具。核心：**将命题推到极端，看它在哪里"断裂"，从而发现其荒谬之处。**

## 概念

### 定义

归谬法的经典形式：
```
假设 P 为真
   ↓
从 P 推导出 Q
   ↓
Q 明显荒谬或矛盾
   ↓
因此 P 为假
```

与[[犯错儿]]的关系：
- 犯错儿：犯了错之后分析它为何"好"
- 归谬法：主动构建错误，看它在哪里崩塌

### 三种形式

| 形式 | 说明 | 例子 |
|------|------|------|
| 直接归谬 | 推导出明显荒谬的结论 | "如果所有规则都有例外，那这条规则也有例外" |
| 反证法 | 推导出矛盾（A且非A） | 欧几里得证明"素数有无穷多个" |
| 等价归谬 | 证明命题等价于荒谬命题 | "你说的等于说..." |

## 价值

| 维度 | 价值说明 |
|------|---------|
| 逻辑检验 | 最强的逻辑检验工具之一 |
| 直觉泵 | 天然是直觉泵——"泵出"隐藏的直觉 |
| 批判武器 | 暴露论证的薄弱环节 |
| 创新工具 | 发现"断裂点"往往意味着新洞见 |

**与犯错儿的协同**：
> 归谬法是"主动犯错"的技术——我们故意接受一个命题，看它能把我们带到哪里。如果带到荒谬之地，我们就发现了它的问题；如果意外发现了新洞见，那更是收获。

## 用法

### 归谬法五步法

```
Step 1: 识别命题
        "X是真的"
        ↓
Step 2: 暂时接受为真
        "假设X是真的..."
        ↓
Step 3: 推到极端
        "如果X为真，那么Y也应该为真"
        ↓
Step 4: 观察断裂点
        "但Y明显荒谬/矛盾"
        ↓
Step 5: 反推结论
        "因此X不成立，或需要修正"
```

### 经典应用模板

**模板一：发现隐藏前提**
```
论证：A → B
归谬：如果 A 为真，那么 C 也应该为真
      但 C 明显为假
结论：A 中隐藏了额外前提
```

**模板二：暴露定义问题**
```
定义：X 是 Y
归谬：按此定义，Z 也应该是 Y
      但 Z 明显不是 Y
结论：定义过于宽泛或狭窄
```

**模板三：发现边界条件**
```
命题：所有 M 都是 P
归谬：考虑极端案例 M'
      M' 是 M 吗？
      如果是，那 M' 是 P 吗？
结论：发现命题的适用边界
```

## 原理

### 为什么归谬法有效？

```
命题的"承重结构"
─────────────────────
     表面主张
    ↙    ↘
  前提A   前提B
    ↓       ↓
  隐含假设C
    ↓
  底层逻辑D
─────────────────────

归谬法 = 往"柱子"上施压
→ 看哪里先裂开
→ 暴露薄弱环节
```

**哲学史视角**：
- 归谬法是哲学家的"压力测试"
- 几乎所有重大哲学突破都用到归谬
- 柏拉图对话录中苏格拉底的核心方法

### 归谬法的局限

| 局限 | 说明 | 对策 |
|------|------|------|
| 只能证伪，不能证实 | 只能证明某命题为假，不能证明其为真 | 与其他工具结合 |
| 依赖"明显荒谬"的直觉 | 什么是"明显"因人而异 | 使用跨文化、跨时代的共识 |
| 可能"归"到错误地方 | 推导过程本身可能有误 | 严格检验每一步推导 |

## 心法

### 归谬法的实践心法

1. **"如果...会怎样？"心态**
   - 保持好奇，而非攻击性
   - 问"这会导致什么后果？"而非"这很愚蠢"

2. **寻找"甜蜜点"**
   - 推得不够远 → 看不到荒谬
   - 推得太远 → 脱离原命题
   - 找到刚好暴露问题的"断裂点"

3. **区分三种"荒谬"**
   ```
   经验荒谬：与已知事实矛盾
      例："如果地球是平，船应该掉下去"
   
   逻辑荒谬：自相矛盾
      例："所有规则都有例外"（这条规则呢？）
   
   直觉荒谬：与深层直觉冲突
      例："意识是幻觉"（谁在体验这个幻觉？）
   ```

4. **警惕"稻草人"**
   - 归谬法不等于攻击稻草人
   - 必须公平地推演，不能扭曲原意
   - 参考[[拉波波特法则]]：先准确理解对方观点

### 与其他工具的协同

```
归谬法 + 犯错儿 = 主动构建好错儿
归谬法 + 拉波波特法则 = 公平的批评
归谬法 + 跳出系统 = 从外部审视假设
归谬法 + 史特金定律 = 只对10%精品用归谬
```

## 实际应用示例

### 哲学中的应用

**苏格拉底 vs 定义正义**
```
定义：正义 = 说真话 + 归还所欠
归谬：如果朋友借了武器后疯了，你还应该归还吗？
      如果归还，可能造成伤害
      如果不归还，违反"归还所欠"
结论：定义不完整，需要加入"恰当性"条件
```

**笛卡尔的"我思故我在"**
```
怀疑一切
   ↓
归谬：连"我在怀疑"都不能怀疑
   ↓
因此：怀疑本身证明了我存在
```

### 数学中的应用

**欧几里得：素数无穷多**
```
假设：素数有限，最大的素数是 P
   ↓
构造：P! + 1（P的阶乘加1）
   ↓
推导：这个数要么是素数，要么有素因子
      如果是素数，比 P 大，矛盾
      如果有素因子，不能是 2,3,5...P 中的任何一个
      （因为除以任何一个都余1）
   ↓
结论：假设错误，素数无穷多
```

### 日常讨论中的应用

**讨论：AI 是否有意识**
```
命题：只有生物才有意识
归谬：那把大脑逐步替换成硅基元件呢？
      替换一个神经元，还有意识吗？
      替换两个呢？
      替换到多少个就"突然"失去意识？
   ↓
断裂点：找不到清晰的"失去意识"边界
结论：命题可能过于简单化，需要重新定义问题
```

**讨论：自由市场完美论**
```
命题：自由市场能解决所有问题
归谬：那环境污染呢？
      企业的"理性选择"是外部化成本
      市场没有机制惩罚这种行为
   ↓
结论：市场失灵存在，需要补充机制
```

## 一句话总结

> 归谬法的核心：**假设对手是对的，然后陪他走到悬崖边，问他是否还想继续前进。** 这是发现命题缺陷的最优雅方式。
