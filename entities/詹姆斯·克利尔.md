# 詹姆斯·克利尔

詹姆斯·克利尔（James Clear），美国作家、演讲者，以《原子习惯》（Atomic Habits）闻名。在书中提及[[卡尔·纽波特]]的晚间停工仪式。

## 背景

- 《原子习惯》作者
- 习惯养成专家
- 演讲者、博主

## 核心贡献

### 原子习惯

《原子习惯》提出：

- **微小改变**：小习惯带来大变化
- **系统优于目标**：关注系统而非目标
- **身份改变**：改变身份认同
- **四定律**：提示、渴望、反应、奖励

### 与深度工作的关联

克利尔在《原子习惯》中：

- 提及纽波特的晚间停工仪式
- 认为习惯化有助于深度工作
- [[链式习惯哲学]]与习惯养成相通

## 晚间停工仪式

克利尔引用纽波特的晚间停工仪式：

1. 最后检查收件箱
2. 将所有新任务转移到任务列表
3. 浏览任务清单和日程表
4. 制定第二天计划
5. 说出"停工完成"，结束工作思考

这个仪式帮助结束工作日，保护晚间休息时间。
