# K·安德斯·艾利克森

K·安德斯·艾利克森（K. Anders Ericsson，1947-2020），瑞典心理学家，佛罗里达州立大学教授，以研究[[刻意练习]]（Deliberate Practice）闻名。其研究被通俗化为"一万小时定律"。

## 背景

- 出生于瑞典
- 佛罗里达州立大学心理学教授
- 专研专业表现和技能习得
- 刻意练习理论创始人

## 核心贡献

### 刻意练习理论

艾利克森提出[[刻意练习]]概念：

- **明确目标**：知道要提升什么
- **专注投入**：全神贯注于练习
- **即时反馈**：知道表现如何
- **重复改进**：持续调整优化

### 一万小时定律

研究发现：
- 专家级表现需要约一万小时刻意练习
- 简单重复不等于刻意练习
- 只有刻意练习才能提升

这一发现被通俗化为"一万小时定律"，但艾利克森强调：

- 重要的是练习质量，不是时间
- 刻意练习有上限（约4小时/天）
- 需要即时反馈和持续改进

## 与深度工作的关联

### 刻意练习与深度工作

艾利克森的刻意练习与[[深度工作]]高度重叠：

| 刻意练习 | 深度工作 |
|---------|---------|
| 无干扰状态 | 无干扰状态 |
| 高度专注 | 高度专注 |
| 即时反馈 | 持续产出 |
| 技能提升 | 价值创造 |

### 练习时间上限

艾利克森发现：
- 刻意练习每日上限约4小时
- 超过后质量严重下降
- 专家也需要休息

这与[[深度工作时间上限]]一致。

## 研究方法

艾利克森研究专家表现：
- 音乐家（小提琴家）
- 运动员
- 棋手
- 医生

发现专家的共同特点：大量刻意练习。

## 启示

艾利克森的研究启示：

1. **天赋不是全部**：刻意练习比天赋更重要
2. **练习需要方法**：简单重复不提升
3. **专注是关键**：练习需要全神贯注
4. **反馈很重要**：知道如何改进
5. **尊重上限**：过度练习有害
