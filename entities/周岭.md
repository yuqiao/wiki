# 概念 (Concept)

个人成长领域作家，公众号"清脑"作者。36岁开始觉醒探索，从脑科学、认知科学、心理学等学科中找到成长方法论，三年内完成蜕变。

代表作：《认知觉醒：开启自我改变的原动力》（2020）

# 价值 (Value)

提供一个普通人可复制的成长路径——不是天才的故事，而是"醒着的睡着的人"如何觉醒的真实案例。

方法论特点：底层理论扎实（脑科学+认知科学），实践门槛低（人生五件套成本低），验证充分（自身+读者双重验证）。

# 用法 (Usage)

## 阅读顺序
建议先读《认知觉醒》理解底层原理，配合公众号"清脑"的后续文章。

## 实践验证
周岭36岁开始改变，4年时间验证方法论有效性。读者反馈"没有鸡汤成分，没有阶层分隔，谁读都有所受益"。

# 原理 (Principle)

成长方法论基于：
- 脑科学：三重大脑进化机制
- 认知科学：元认知、模糊消除
- 心理学：心智带宽、心流状态
- 行为科学：习惯养成、增强回路

# 心法 (Best Practices)

## 方法论核心

- 用知识驱动理性和感性两种力量
- 消除认知、情绪、行动的模糊
- 每日反思保持觉知
- 在舒适区边缘持续迭代
