# 概念 (Concept)

周岭所著的个人成长方法论书籍，副标题"开启自我改变的原动力"。从脑科学、认知科学角度剖析成长的底层逻辑，提出"人与人之间的根本差异是认知能力上的差异"。

全书分上下两篇：
- 上篇"内观自己，摆脱焦虑"：大脑结构、潜意识、元认知
- 下篇"外观世界，借力前行"：专注力、学习力、行动力、情绪力、人生五件套

# 价值 (Value)

解决"醒着的睡着的人"困境——虽然每天有事情做、每天都努力，但真正觉醒需要发自内心的渴望，立足长远，保持耐心。

核心命题：认知影响选择，选择改变命运。成长的本质是让大脑的认知变得更加清晰。

# 用法 (Usage)

## 阅读建议
全书理论很底层，建议先读上篇理解大脑机制，再读下篇实践方法论。

## 配套实践
- [[每日反思]]：每天复盘最触动自己的点
- [[人生五件套]]：早起、冥想、阅读、写作、运动
- [[匹配]]：在舒适区边缘成长

# 原理 (Principle)

基于脑科学和认知科学：
- [[三重大脑]]：本能脑、情绪脑、理智脑的进化与博弈
- [[模糊]]：认知、情绪、行动三种模糊的消除
- [[元认知]]：审视自身思考的终极能力

# 心法 (Best Practices)

## 最佳实践

- 先理解原理再行动，避免盲目努力
- 用理智脑驱动本能脑和情绪脑，而非对抗
- 每日反思是最低成本的成长方式
- 在舒适区边缘持续挑战

## 反模式

- 只读不实践——知道和做到相差十万八千里
- 迷恋打卡——打卡打不出未来
- 过度刻苦——你没成功可能是因为太刻苦了（缺乏休息）
- 贪多求快——急于求成导致心智带宽不足
