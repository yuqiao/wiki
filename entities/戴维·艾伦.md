# 戴维·艾伦

戴维·艾伦（David Allen），美国生产力顾问，以GTD（Getting Things Done）方法论闻名。GTD与[[深度工作]]可以互补：GTD管理浮浅工作，深度工作专注重要产出。

## 背景

- GTD方法论创始人
- 生产力顾问、培训师
- 《搞定》系列作者

## 核心贡献

### GTD方法论

GTD（Getting Things Done）是一套个人管理系统：

- **收集**：将所有事务收集起来
- **整理**：分类处理
- **组织**：放入相应清单
- **回顾**：定期回顾
- **执行**：根据情境选择任务

### 与深度工作的关系

GTD与[[深度工作]]的关系：

| GTD | 深度工作 |
|-----|---------|
| 管理浮浅工作 | 专注深度工作 |
| 处理日常事务 | 创造重要产出 |
| 收集、整理、执行 | 无干扰专注 |

**互补性**：
- GTD帮助管理[[浮浅工作]]
- 深度工作聚焦[[深度工作概念]]
- 两者结合：用GTD清理浮浅，保护深度时间

### GTD的局限

纽波特认为GTD侧重浮浅工作管理，而深度工作更关注：

- 专注重要事项
- 减少浮浅工作
- 创造有价值产出

## 主要著作

-《搞定：青年版》（Getting Things Done for Teens，2017）
