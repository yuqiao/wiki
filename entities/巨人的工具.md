# 巨人的工具

## What
蒂姆·费里斯所著的成功学书籍，汇集了 200+ 位世界级成功人士的智慧、习惯和工具。全书 435 页，分为三个部分：健康、财富、智慧。

## Key Facts
- 作者：蒂姆·费里斯（Tim Ferriss）
- 出版社：中信出版集团
- 原版：Tools of Titans（2016）
- 中文译者：杨清波
- 页数：435 页

## Structure
| 部分 | 内容 |
|------|------|
| 健康 | 运动训练、营养补充、睡眠优化、心智训练 |
| 财富 | 商业思维、投资策略、创业经验、谈判技巧 |
| 智慧 | 思维方法、人生哲学、写作创作、学习能力 |

## Core Themes
- **80%+ 成功人士** 进行某种形式的冥想或内观禅修
- **45岁以上男性** 多人不吃早餐或只吃少量食物
- **共同推荐书籍**：《人类简史》《穷查理宝典》《影响力》《活出生命的意义》
- **核心信念**："失败不会长久"
- **共同特质**：将明显的"缺点"转化为超强竞争优势

## Key Concepts
- [[悉达多的三能力]] — 思考、等待、禁食
- [[10倍思维]] — 10倍增长比10%增长更容易
- [[1000个真正的粉丝]] — 凯文·凯利的粉丝经济理论
- [[晨间笔记]] — 解决问题的日记方法
- [[自我肯定咒语]] — 重塑信念的心理技术
